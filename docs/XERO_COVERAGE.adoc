== Not in the specs

* *Webhooks* (invoice, contact and other events) are configured in the Xero developer portal, not described in these specs. In progress.
* *Reports/BankStatement* is documented by Xero but not in the OpenAPI spec. It answers 401 to Bookie's connection, so bank statement lines and a running balance are not available. The account register says so.
* *Account Transactions* and *General Ledger* reports have no API endpoint (404). Bookie builds Account Transactions and the Journal Report from `GET /Journals`, which covers posted transactions on the accrual basis.
* Xero's *Short-term cash flow* projection has no API. Bookie's Reporting › Cash flow forecast builds its own from the Bank Summary balances, unpaid invoices and bills by due date (overdue ones kept apart), the user's planned items (sealed in the tenant's settings), and, only when switched on, an average of spend and receive money from `GET /BankTransactions` (invoice and bill payments excluded).
* *Bank reconciliation* has no API. Bookie shows each transaction's reconciled flag and filters on it; reconciling happens in Xero.
* *Employees* in the Accounting API is no longer in the spec and answers 404 for UK organisations; UK employees come from the Payroll UK API.
