# Code of conduct

Be kind, be constructive, and assume good intent. Harassment, discrimination and personal attacks aren't welcome in issues, pull requests or any other project space.

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Report concerns privately to **support@knowall.ai**; we'll respond promptly and confidentially.
